## 🚀 Descripción

**EcoDynamics** es una aplicación web interactiva que permite simular el comportamiento de la economía familiar en diferentes escenarios como inflación, escasez, consumo y transporte.

El proyecto combina teoría económica con programación para ofrecer una experiencia visual, dinámica y educativa.

---

## 🖥️ Vista General

* 📊 Dashboard interactivo con indicadores en tiempo real
* 📈 Gráficas dinámicas generadas automáticamente
* 🧠 Interpretación inteligente de resultados
* 🌗 Modo claro / oscuro
* 📱 Diseño responsive

---

## 🧩 Módulos del Sistema

| Simulador            | Descripción                       |
| -------------------- | --------------------------------- |
| 📦 Abastecimiento    | Evalúa disponibilidad de recursos |
| 📈 Inflación         | Calcula variación de precios      |
| 🚚 Transporte        | Analiza costos adicionales        |
| 🛒 Compras           | Compara presupuesto vs gasto      |
| 📢 Rumor             | Simula demanda por pánico         |
| 💰 Poder adquisitivo | Relación ingresos vs gastos       |
